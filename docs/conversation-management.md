# 会话删除

用户要求在左侧对话列表加入单个删除和全部删除选项，沿用现有配色及侧栏结构。

- 会话行右侧的垃圾桶在桌面悬停/键盘聚焦时出现，手机上直接显示。
- 会话列表下方提供「删除全部会话」，无会话时禁用。
- 确认框展示会话标题或清空数量，说明会话及全部版本会永久删除。取消不发起删除请求。
- 删除当前会话或清空后，教程、版本和状态重置，页面回到新教程；删除其他会话保留当前内容。
- 删除失败保留历史与确认框，显示可重试错误；请求期间禁用重复操作。
- 会话与版本在同一 SQLite 事务中删除。生成中的会话不能被删除；清空时如有生成任务则拒绝。
- 已删除会话的延迟列表请求及状态上传不会恢复记录或在新教程显示无关错误。
- 确认框约束键盘焦点，取消回到删除入口；入口已删除或不可用时回到可见的新教程/侧栏切换按钮。

本功能是现有视觉系统的局部扩展：会话行保留暖灰选中底、13px 系统字体、8px 圆角和标题省略；删除确认使用现有 destructive 按钮及砖红错误文字。确认框桌面宽度上限 420px，窄屏保留两侧各 16px 空间，采用暖纸底、16px 圆角，并复用模型配置弹窗的遮罩、阴影与进入动画。手机（720px 以下）直接显示行删除入口，确认框内边距从 26px 缩为 23px；关闭抽屉后焦点不返回屏外控件。

以上记录以 `frontend/src/components/DeleteConversation.tsx`、`frontend/src/App.tsx` 和 `frontend/src/index.css` 为依据。根目录 `DESIGN.md` 与 `.impeccable/design.json` 保留既有规范；它们尚未收录已有模型配置弹窗的组件、遮罩、阴影和动画，这是删除功能之前的文档差异，本次不扩展全局设计规范。

验收使用临时 SQLite 数据库和浏览器模拟历史，不对用户的已有会话执行删除。测试覆盖单个删除、全部删除、取消、当前会话重置、其他会话保留、事务回滚、生成中保护、来源校验、失败重试及手机焦点。
