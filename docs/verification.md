## 当前限制

- 已配置本机模型密钥；本记录的验收使用固定样例与模拟接口，未核验真实 DeepSeek 端到端生成质量。模型配置可从页面弹窗修改，保存后立即应用；不要将密钥提交到 Git。
- 自由算法由模型生成；五个样例有数值核验，任意新算法的数学正确性不由沙箱保证。模型输出错误会显示诊断，已有可运行快照尽量保留。
- 场景使用通用几何与可组合数据，支持自由构图；首版不支持任意 Three.js 代码、shader、远程纹理或第三方包导入。
- 计算用于小型教学数据。Worker 超时和序列化预算可限制常见失控程序，但没有操作系统级内存/GPU硬配额。
- 下一轮包含所选上一版源码及最新状态；没有长会话的语义检索或摘要。
- Three.js、KaTeX 等造成 Vite 的大 chunk 提示；三维渲染器已延迟加载，当前生产资产约 2.8 MB（未压缩，包含数学字体）。
- Python 测试有 Starlette/httpx 兼容层的弃用提示，测试通过。
