## 用一次完整学习过程定义产品

用户输入一个机器学习或深度学习算法及希望演示的内容。WindGen 调用 DeepSeek 或其他 OpenAI 兼容模型，生成带公式、计算逻辑和交互界面的教程。结果逐渐出现在对话中，用户可以调参数、单步查看、播放/暂停、重置。按教学需要使用公式、表格或二维图表；仅在三维确实有助于理解或用户明确要求时生成三维场景。所有教学计算在本地浏览器完成。

2026-10-11 用户补充：部分算法无需三维，只在需要时生成三维。三维作为可选能力与表达验收，不是每份生成教程的必备结构；后续修改也应重新判断是否需要三维。

用户继续提问，例如“解释现在这一步的梯度”或“把学习率改成 0.1 并对比”。模型获得当前参数、步骤和选中对象等必要状态，更新同一个演示。旧版本仍可以查看，每个版本保留自己的参数和演示状态。

面向已有基础的学习者；重点是公式、实现步骤、变量/张量维度以及中间数值与可视化的对应，而非只有抽象动画。

## 教程应提供的信息

以下是依据已确认需求整理的交付清单：

- 数学对象与定义：算法的目标、公式、变量和张量维度。
- 输入与参数：可复现数据、初始状态、可编辑参数和单位/范围。
- 执行过程：当前阶段、当前步骤、更新前后数值、关键中间量。
- 可视化：适合算法的二维/三维表达；相机变化与算法状态变化清楚区分。
- 控制：单步、播放/暂停、重置及播放速度，尽量按算法阶段推进。
- 检查：点击对象或选择步骤时，可以看到对应公式、数值与简短实现片段。
- 持续提问：当前状态作为上下文，保持模型输出与正在查看的演示一致。

## 验收场景

三个场景是验收样本，不是算法白名单。详细数学核验见 [算法教学研究](research/algorithm-teaching.md)。

1. **线性回归与梯度下降。** 查看数据、损失、梯度、参数更新与下降轨迹；小样本的一步数值必须正确，学习率过大时显示真实发散行为。
2. **K-means。** 分别演示分配与更新中心；查看距离、簇归属和目标值；空簇、相同距离等边界有明确行为。
3. **小型神经网络。** 分开前向、损失、反向求梯度和应用更新；查看节点、边、激活、导数和权重变化，梯度用独立数值检查核验。

Q13 已选择问题中给出的例子，增加以下三维验收。其中优化粒子可以与梯度下降场景共用，卷积和注意力作为场景表达能力的补充验收：

4. **卷积张量块。** 以小型输入张量、卷积核、输出块展示卷积核滑动。单步移动窗口、突出参与计算的元素并显示对应乘加及输出；修改步长/核参数时同步重算。数值与输出尺寸按照明确的padding/stride约定校验。
5. **注意力空间节点。** 展示小规模token节点、Q/K/V及注意力连接。选择token或连线可检查分数、softmax权重与加权输出；播放按分数计算、归一化、汇总分阶段推进。空间位置表示布局，权重表示attention，不混淆二者。
6. **优化运动。** 小粒子或移动标记随实际参数更新沿轨迹移动；能查看当前位置、梯度、损失和步长，暂停及单步可复现。视觉插值只平滑展示，不改变算法数值。

这些例子通过通用物体、组、变换、连线、网格、标签及事件表达，避免把产品只做成几个固定算法组件。模型生成教学计算与场景数据，宿主负责渲染。

## 通用行为验收建议

- 用户操作参数或执行一步时不调用模型，算法数值和视觉显示同步更新。
- 流式生成不重置已经调整过的状态；未完成或错误片段保留上一份可运行界面。
- 发送下一轮时直接携带最新客户端快照，避免刚调参数立即提问却读到旧值。
- 取消、模型错误与计算错误分别显示，用户可恢复已有演示；错误不标记为生成成功。
- 刷新后可恢复会话与版本；旧版本查看和继续修改的入口明确。
- 生成程序在隔离运行时执行，宿主渲染受控组件与场景，执行超时可终止。
- 真实模型、开发用固定样例、数值正确性、浏览器隔离分别验证并记录证据。

## 工程建议（未作为用户选择记录）

Python 负责模型请求、会话/版本和状态存储，采用 FastAPI 与 SQLite。TypeScript 文档编译器在独立 Worker 中做解析，模型生成的计算程序在 iframe 内的隔离 Worker 中运行。React + shadcn/ui 渲染普通组件，Three.js 与 React Three Fiber 支持三维宿主；算法逻辑与渲染器分离。首版场景原语支持组、位置/旋转/缩放、基础物体、点/线、曲面或自定义几何数据、文本标签、颜色/透明度及点选事件，以支撑用户选择的三类表达。

参考仓库有 MIT 许可证，可以迁移部分编译与恢复逻辑并保留许可；其直接 DOM 渲染、内存会话以及不完整的取消/状态同步应替换。框架细节由代理依据已确认约束选择，不再逐项要求用户决策。
